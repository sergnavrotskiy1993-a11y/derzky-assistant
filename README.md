# Дерзкий ассистент — локальное Android-приложение

Android-приложение на Kotlin и Jetpack Compose. Чат, карточки-слайды и история работают локально на телефоне; аккаунт и сервер не нужны.

## Реализовано
- **Чат:** сохраняет переписку на устройстве и отвечает простыми встроенными правилами (приветствие, дата и время, подсказки для планирования и навигация по приложению). Это локальный помощник, не облачная языковая модель.
- **Приложения:** быстрые действия открывают доступные на устройстве браузер, телефон, почту, календарь и настройки через стандартные Android intents. Разрешение на контакты или звонки не запрашивается.
- **Слайды:** создание, просмотр, переключение и удаление карточек; данные хранятся локально.
- **Конфиденциальность:** приложение не отправляет чат или карточки в сеть и не содержит API-ключей. Браузер при явном выборе открывает веб-страницу, для которой интернет предоставляет уже выбранное приложение.

## Сборка
Откройте репозиторий в Android Studio и запустите конфигурацию `app`. Для APK выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Облачный workflow Codemagic находится в `codemagic.yaml`.

## Ограничения
Ответы чата формируются простыми локальными правилами и не обладают возможностями ChatGPT или ElevenLabs. Реальное распознавание/синтез речи, облачный ИИ и веб-поиск здесь не подключены.
