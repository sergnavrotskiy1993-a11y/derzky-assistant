# Дерзкий ассистент — Android starter

Исходный проект Android Studio на Kotlin и Jetpack Compose. В корне находится Android-модуль `app` со стартовым экраном чата.

## Что реализовано
- Русскоязычный интерфейс чата в тёмной теме.
- Отправка и отображение текста в локальном дем��-экране.
- Сохранение черновика и истории сообщений при пересоздании Activity.
- Адаптация поля ввода к экранной клавиатуре и автоматическая прокрутка к последнему сообщению.
- Доступный текстовый интерфейс; голосовой режим явно обозначен как неподключённый.

## Что нужно подключить для полноценного ассистента
1. Серверный endpoint, который выдаёт короткоживущий токен/подписанный URL для ElevenLabs.
2. Подключение Android-клиента ElevenLabs и безопасную обработку разрешения микрофона.
3. Ответы ассистента и поиск в интернете через серверные API.
4. Обработку состояния соединения, сетевых ошибок, тесты на устройствах и подпись release APK.

Не помещайте ElevenLabs API key или поисковые ключи непосредственно в APK. Ключи должны храниться на сервере. Сейчас экран чата — UI-демо: он не отправляет сообщения в сеть и не имитирует ответ ассистента.

## Сборка
Откройте репозиторий в Android Studio и запустите конфигурацию `app`. Для APK выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

В корне также находится `codemagic.yaml` для облачной сборки debug APK. Подключите репозиторий в Codemagic и запустите workflow `android-debug-apk`. Для постоянного распространения настройте подпись release-сборки.
