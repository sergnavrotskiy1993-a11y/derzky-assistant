# Дерзкий ассистент — Android starter

Это исходный проект Android Studio (Kotlin + Jetpack Compose), а не готовый APK.
Он содержит стартовый интерфейс чата и разрешения для сети и микрофона.

## Уже создано
- ElevenLabs-агент на русском языке с мужским голосом и выбранной манерой общения.
- Android-проект с экраном чата и элементами управления.

## Что ещё нужно подключить
1. Серверный endpoint, который выдаёт короткоживущий токен/подписанный URL для ElevenLabs.
2. Подключение Android-клиента ElevenLabs к этому endpoint.
3. Поиск в интернете через серверный поисковый API.
4. Обработку разрешения микрофона, состояний соединения и ошибок.
5. Иконку приложения, тестирование на конкретном устройстве и сборку release APK.

**Важно:** не помещайте ElevenLabs API key или поисковые ключи непосредственно в APK.
Ключи должны храниться на сервере. В проекте намеренно нет секретов и фиктивной реализации
голосового соединения или интернет-поиска.

## Сборка стартового проекта
Откройте папку в Android Studio, дождитесь синхронизации Gradle и запустите `app`.
Для APK: Build → Build Bundle(s) / APK(s) → Build APK(s).
Для распространения нужен отдельный release signing key.


## Облачная сборка без компьютера
В корне проекта добавлен `codemagic.yaml` для сборки debug APK в Codemagic.
Сервис требует, чтобы проект находился в GitHub, GitLab или Bitbucket, после чего
репозиторий нужно подключить в Codemagic и запустить workflow. Сборка появится
в разделе artifacts после успешного завершения. Для установки на телефон debug APK
подходит для первичной проверки; для постоянного распространения лучше настроить
подпись release-сборки.
